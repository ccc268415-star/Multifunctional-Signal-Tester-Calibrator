# Multifunctional-Signal-Tester-Calibrator
基于AMD Kintex-7 FPGA构建信号测调平台。系统采用双路ADC与两个单路DAC模块，实现模拟信号的实时采集、实时显示以及同步或独立输出；支持边沿触发，可测量幅值、频率、周期、占空比、时间差和相位差，并通过FFT显示幅度频谱。双路信号源可产生正弦波、方波、三角波和锯齿波，并支持频率、幅度、相位、直流偏置及占空比调节；可对AM、FM、ASK、PSK和FSK信号进行参数化生成与解调，恢复基带波形和数字比特。TFT触控屏用于显示时域波形、频谱、实时参数，并支持模式切换、参数调节。系统采用PL端与MicroBlaze软核协同架构，支持串口参数配置和测量结果读取，最终构建灵活可扩展的综合信号测调平台。
